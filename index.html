ESP32 CONNECTION & HOTSPOT SETUP

Endpoint: http://<IP>/status and /motor?speed=VALUE

Windows Hotspot Quick Instructions:

  1. Enable Mobile Hotspot in Windows Network Settings.
  2. Connect ESP32 to the hotspot SSID and password.
  3. In Windows Command Prompt, run arp -a to verify the ESP32 IP (usually 192.168.137.xxx).
  4. Enter the IP address above and click Test Status.
